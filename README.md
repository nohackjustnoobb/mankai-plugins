# Mankai Plugins

This repository contains JavaScript plugins for [mankai](https://github.com/mankai-app/mankai).

You can find the compiled plugins in the [static branch](https://github.com/nohackjustnoobb/mankai-plugins/tree/static).

## Development

This project uses [Bun](https://bun.sh/).

Install dependencies with:

```bash
bun install
```

### Build

To build the plugins:

```bash
bun run build
```

This will generate the output in the `dist/` directory.

### Dev

To run in development mode:

```bash
bun run dev
```
